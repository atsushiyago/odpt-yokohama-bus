# 横浜市営バス遅延 × 代替シェアサイクル空き状況マップ

横浜市営バスのリアルタイム運行遅延情報と周辺のシェアサイクル空き状況を地図上で重ね合わせ、「次のバスを待つか、徒歩圏のシェアサイクルへ乗り換えるか」を即座に判断できる Web アプリケーションです。

## 本番 Web アプリ

- **公開 URL**: https://odpt-yokohama-bus-687077680653.asia-northeast1.run.app/

### スマートフォンから開く（QRコード）

<img src="assets/qrcode.png" width="180" alt="スマートフォン用QRコード">

スマートフォンのカメラで上記 QR コードを読み取ると、外出先やバス停からそのまま Web アプリを開けます。

## 主な機能

1. **遅延バス停のリアルタイム可視化（ODPT GTFS / GTFS-RT）**
   - 横浜市営バスのリアルタイム遅延データと静的時刻表を照合し、基準時刻の前後（-5分〜+30分）に到着予定で指定分数以上遅れているバス停を抽出・分類（回避可能 / 空き0台 / ポート空白）して地図に表示します。
2. **次のバス到着予測**
   - 選択したバス停における先発便・後続便（最大3件）の到着予測時刻と残り分数、遅延時間を表示します（60秒ごとに自動更新、タブ・画面復帰時の即座再取得対応）。
3. **半径 300m 以内のシェアサイクル空き状況・所要時間比較**
   - HELLO CYCLING およびドコモ・バイクシェア（NOLL）の GBFS リアルタイムデータから最寄り貸出可能ポート上位 3 件を案内し、目的地側の返却可能ラック状況（満車注意含む）を踏まえた「バス待ち vs 自転車切替」の所要時間比較を行います。
4. **マイバス停登録と直通 URL（`?stop_id=...`）**
   - よく使うバス停をブラウザ（`localStorage`）に最大 5 件登録でき、ワンタップでの呼び出しや起動時の自動選択、遅延アラート通知に対応しています。`?stop_id=<stop_id>` 付きの直通 URL コピーも可能です。
5. **平日・土日祝別の遅延傾向分析（データ分析タブ）**
   - 蓄積した遅延・ポート空きスナップショットをもとに、すべて / 平日 / 土日祝ごとの課題バス停ランキング（空き0台率・ポート空白率・目的地満車リスク）、時間帯別推移グラフ、系統別テーブルでボトルネックや再配置・ポート新設候補地を分析できます。

## 技術構成・データ出典

- **バックエンド / フロントエンド**: Python（FastAPI） / Leaflet / Chart.js
- **データ出典**: 公共交通オープンデータセンター（ODPT）を通じて提供される横浜市交通局（GTFS / GTFS-RT）、OpenStreet株式会社（HELLO CYCLING）、株式会社ドコモ・バイクシェア（GBFS）のデータを利用しています。
